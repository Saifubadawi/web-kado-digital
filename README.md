# 🎁 Digital Gift Web

Website kado digital interaktif yang dirancang untuk memberikan pengalaman pemberian hadiah secara lebih personal dan menarik melalui rangkaian animasi, pesan, musik, dan interaksi pengguna.

## ✨ Tentang Project

**Digital Gift Web** adalah proyek website interaktif yang dibuat sebagai media untuk memberikan kado secara digital.

Website ini menggunakan konsep **storytelling interaktif**, sehingga penerima kado tidak langsung melihat seluruh isi hadiah. Setiap bagian muncul secara bertahap melalui animasi dan interaksi pengguna.

Alur utama website:

**🕯️ Lilin → 🎁 Kado → 💌 Pesan → 💖 Ucapan → 🎉 Surprise**

Project ini dibuat sebagai latihan sekaligus penerapan kemampuan dalam pengembangan website frontend, khususnya pada bagian animasi, interaksi pengguna, responsive design, dan user experience.

## 🎯 Tujuan Project

Project ini bertujuan untuk:

* Membuat pengalaman pemberian kado yang lebih personal.
* Menerapkan animasi pada website.
* Membuat alur interaksi pengguna yang menarik.
* Menerapkan responsive design.
* Mengembangkan kemampuan HTML, CSS, dan JavaScript.
* Membuat project yang dapat digunakan sebagai portfolio.

## 🚀 Fitur

### 🕯️ Interactive Candle

Pengguna memulai pengalaman dengan menyalakan lilin melalui interaksi pada halaman.

### 🎁 Gift Animation

Setelah tahap lilin selesai, website menampilkan animasi kado sebagai transisi ke bagian berikutnya.

### 💌 Personal Message

Website menampilkan pesan khusus setelah animasi sebelumnya selesai.

### 💖 Interactive Menu

Pengguna dapat memilih menu atau bagian tertentu untuk melanjutkan perjalanan di dalam website.

### 🎵 Background Music

Website dapat menggunakan musik latar untuk membangun suasana selama pengalaman berlangsung.

### 📱 Responsive Design

Tampilan dirancang agar dapat digunakan pada berbagai ukuran layar, terutama smartphone.

### ✨ Animation & Transition

Setiap halaman menggunakan transisi dan animasi untuk membuat perpindahan antarbagian terasa lebih interaktif.

## ▶️ Cara Menjalankan Project

Clone repository:

```bash

```

Masuk ke folder project:

```bash
cd digital-gift-web
```

Kemudian buka:

```text
index.html
```

di browser.

Project ini tidak membutuhkan backend sehingga dapat dijalankan langsung melalui browser.
